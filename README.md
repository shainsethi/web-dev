## 🚀 Setup & How to Study

1.  **Read Study Guides**: Each subdirectory has a dedicated, easy-to-read `README.md` outlining syntax rules, visual structures, and terminology definitions.
2.  **Open Examples in Browser**: Open the `.html` files in any standard browser to inspect rendering styles, layout behaviors, hover transitions, and responsive triggers live.
3.  **Run Javascript in REPL**: Run code files inside the `Js/` folder using Node or by opening a browser Console developer tool.
4.  **No Code Comments rule**: All code examples are kept clean and comment-free so you can read real-world standard source code without visual clutter.
