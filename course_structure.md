# Web Development Mastery Course

Welcome to the Web Development Mastery Course! This document outlines your structured curriculum, learning path, and file mapping for mastering front-end and fundamental web development.

---

## 🗺️ Learning Roadmap

### 📦 Module 1: Introduction to the Web
Understand the fundamentals of how the internet works, the client-server model, DNS, and IP addresses.
- **Topics**: Clients and Servers, DNS, IP Addresses, packets, browser rendering stages, and what is Web Development.
- **Reference Notes**: [Chapter 1: Internet & Web Development](file:///home/shain/Workspace/Web%20development/notes/Chapter_1_Internet_and_Web_Development.md)

### 📦 Module 2: HTML Part 1 (Elements, Media & Lists)
Learn standard HTML skeleton structures, headings, paragraphs, list types, and embedding external links/images.
- **Topics**: HTML elements & tags, document boilerplate, headings, paragraphs, lists (ul, ol, dl, nested), attributes, anchors (hyperlinks, bookmarks), image elements, line breaks, horizontal rules, and comments.
- **Reference Notes**: [HTML Part 1 Study Guide](file:///home/shain/Workspace/Web%20development/HTML/part_1/README.md)
- **Practice Folder**: `/home/shain/Workspace/Web development/HTML/part_1/`

### 📦 Module 3: HTML Part 2 (Semantics & Formatting)
Master inline vs block-level elements, divisions, formatting markup tags, HTML entities, and browser parsing stages.
- **Topics**: Block vs inline elements, container divisions (div/span), formatting tags (hr, sup, sub), semantic layout tags, HTML entities, Emmet shorthand syntax, and browser rendering logic.
- **Reference Notes**: [HTML Part 2 Study Guide](file:///home/shain/Workspace/Web%20development/HTML/part_2/README.md)
- **Practice Folder**: `/home/shain/Workspace/Web development/HTML/part_2/`

### 📦 Module 4: HTML Part 3 (Tables & Forms)
Build structured tables and interactive form layouts using native inputs, controls, and validations.
- **Topics**: HTML tables, table semantic elements (thead, tbody, tfoot, tr, th, td), column/row spans, forms, placeholders, labels, name attributes, checkboxes, radios, select menus, range sliders, textareas, and buttons.
- **Reference Notes**: [HTML Part 3 Study Guide](file:///home/shain/Workspace/Web%20development/HTML/part_3/README.md)
- **Practice Folder**: `/home/shain/Workspace/Web development/HTML/part_3/`

### 🎨 Module 5: CSS Fundamentals (Parts 1 - 3)
Learn CSS inclusion formats, color models, typography, selector rules, cascading specificity, the Box Model, displays, and relative scaling units.
- **Topics**: CSS inclusion formats, HEX/RGB/HSL color systems, alignment, line heights, universal/combinator/attribute selectors, pseudo-classes, pseudo-elements, specificity scores, inheritance, cascading rules, the Box Model (padding, border, margin), box-sizing configurations, block/inline/inline-block displays, and relative scaling units (`%`, `em`, `rem`).
- **Reference Notes**: [CSS Master Syllabus](file:///home/shain/Workspace/Web%20development/CSS/README.md)
- **Practice Folders**: 
  - [Part 1: Syntax, Colors & Typography](file:///home/shain/Workspace/Web%20development/CSS/part_1/)
  - [Part 2: Selectors, Specificity & Cascade](file:///home/shain/Workspace/Web%20development/CSS/part_2/)
  - [Part 3: Box Model, Display Modes & Units](file:///home/shain/Workspace/Web%20development/CSS/part_3/)

### ⚡ Module 6: Modern CSS Layouts & Animations (Parts 4 - 6)
Master transitions, 2D transforms, positioning configurations, the Flexbox layout engine, CSS Grid template structures, keyframe animations, mobile-first queries, and z-index ordering.
- **Topics**: Opacity vs alpha channels, transitions, 2D transform operations (rotate, scale, translate, skew), box shadows, positioning systems (relative, absolute, fixed, sticky), Flexbox containers & items, CSS Grid template areas, keyframe timelines, mobile-first responsive media queries, orientation constraints, and z-index depth stacks.
- **Practice Folders**: 
  - [Part 4: Transforms, Positions & Smiley Face](file:///home/shain/Workspace/Web%20development/CSS/part_4/)
  - [Part 5: Flexbox Layout Engine](file:///home/shain/Workspace/Web%20development/CSS/part_5/)
  - [Part 6: Grid, Animations & Responsive Design](file:///home/shain/Workspace/Web%20development/CSS/part_6/)

### 🚀 Module 7: Tailwind CSS Crash Course
Learn modern utility-first workflow using the Tailwind CSS framework, spacing scales, variants, screen responsive prefixes, and state modifiers.
- **Topics**: Utility-first styling philosophy, Play CDN usage, spacing and typography token scales, interactive states (`hover:`, `focus:`), responsive screen width prefixes (`md:`, `lg:`), and comparative layouts.
- **Reference Notes**: [Tailwind CSS Study Guide](file:///home/shain/Workspace/Web%20development/CSS/tailwindcss/README.md)
- **Practice Folder**: [Tailwind Crash Course](file:///home/shain/Workspace/Web%20development/CSS/tailwindcss/)

### 🧠 Module 8: JavaScript Fundamentals (Part 1)
Learn the absolute basics of programming in JavaScript. Understand console outputs, the REPL shell, case-sensitivity, dynamic typing, primitive data types, number conversions, and operator precedence.
- **Topics**: Console logs, REPL terminal loop, case sensitivity, dynamic variable typing, the 7 Primitive Data Types (Number, Boolean, String, Undefined, Null, Bigint, Symbol), negative/decimal numbers, modulo & power operations, NaN (Not a Number), boolean conversions (unary `+`, `Number()`, `~~`), type checking with `typeof`, and operator precedence hierarchy.
- **Reference Notes**: 
  1. [JavaScript Fundamentals Syllabus (README.md)](file:///home/shain/Workspace/Web%20development/Js/README.md)
  2. [JavaScript Part 1 Study Guide (part_1.md)](file:///home/shain/Workspace/Web%20development/Js/part_1/part_1.md)
- **Practice Folder**: `/home/shain/Workspace/Web development/Js/part_1/`

## 📈 Learning Recommendations

1. **Read & Code**: Read the notes first, then write your own HTML, CSS, and JS files to test the concepts.
2. **Review Exercises**: Open and modify your existing exercises (e.g. `Forms.html` or `second.html`) to apply the new concepts you learned.
3. **Build Projects**: Start a small project after finishing Module 3, such as a landing page or personal portfolio, to solidify your knowledge of Flexbox and Grid.
