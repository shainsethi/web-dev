# Git & GitHub Course

Welcome to the Git & GitHub section! This part covers version control, branches, collaboration, and fixing mistakes.

All examples are simple, uncommented Bash scripts in this directory. They create temporary practice repositories, use a local folder in place of GitHub, and clean up afterward.

> [!TIP]
> **Study Guide Available**: For step-by-step explanations, read the [git.md Study Guide](git.md).

---

## 🏃 How to Run the Examples

Open a terminal in this directory and run any file with `bash`:

```bash
bash 09_add_commit_commands.sh
```

On Windows, use **Git Bash**. The scripts need Git 2.28 or newer. `practice_setup.sh` is the shared setup used by every lesson.
