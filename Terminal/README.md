# Terminal Fundamentals Course

Welcome to the Terminal section! This part covers the commands you need to move around your computer and manage files.

All examples are simple, uncommented Bash scripts in this directory. They work inside a temporary practice folder and clean it up afterward.

> [!TIP]
> **Study Guide Available**: For step-by-step explanations, read the [terminal.md Study Guide](terminal.md).

---

## 🏃 How to Run the Examples

Open a terminal in this directory and run any file with `bash`:

```bash
bash 04_basic_commands.sh
```

On Windows, use **Git Bash**.
