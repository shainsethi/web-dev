2. Specificity: Class vs Element selector

This text is purple. Even though "div p" is more specific than just a tag, the class ".highlight-text" has a higher specificity value (10 vs 2).

This text is orange. The ID selector "#unique-item" has higher specificity (100) than the class ".text-item" (10).

4. Overriding with !important

This text is teal. The !important rule on the class overrides the higher specificity ID selector (#override-id would normally make it pink).
