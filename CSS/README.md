# CSS Course Syllabus (Parts 1 - 6 + Tailwind CSS)

Welcome to the CSS section of your Web Development course! This course is structured into six parts plus a separate Tailwind CSS crash course. It covers basic rules, selectors, the box model, transitions, transforms, positioning, Flexbox, Grid, keyframe animations, and utility-first styling.

Each part contains clean, uncommented code files inside its folder, alongside a detailed study guide.

---

## 🏃 Study Strategy

1.  **Read the Guide**: Open the `README.md` inside any part folder to learn the rules and syntaxes.
2.  **Inspect the Code**: Review the clean code and HTML files inside the folder to see how styles are applied.
3.  **Run in Browser**: Open the `.html` files in your browser to inspect styles and hover effects live!
