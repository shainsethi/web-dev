## 🏃 Study Strategy

1.  **Read the Guide**: Open the `README.md` inside any part folder to read about the concepts and syntax rules.
2.  **Inspect the Code**: Review the clean `.html` files in each subdirectory to see how they are structured.
3.  **Run in Browser**: Open the `.html` files directly in your web browser (double-click in file explorer) to see how they render and interact on-screen.
